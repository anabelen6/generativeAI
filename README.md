## 📌 Overview
This repository serves as a centralized showcase for hands-on projects, experiments, and production-oriented workflows in **Generative AI** and **Large Language Models (LLMs)**. It covers practical implementations ranging from Retrieval-Augmented Generation (RAG) to model fine-tuning and intelligent agent orchestration.

---

## 🛠️ Key Topics & Implementations

### 1. 🔍 Retrieval-Augmented Generation (RAG)
* Advanced document chunking, embedding generation, and vector indexing (using tools like FAISS / ChromaDB / Pinecone).
* Context retrieval and synthesis pipeline for domain-specific Q&A.

### 2. 🎯 Prompt Engineering & Agentic Workflows
* System prompt design, few-shot prompting, and structured output formatting.
* Autonomous agentic workflows using orchestration frameworks (LangChain / LlamaIndex / CrewAI).

### 3. ⚙️ LLM Fine-Tuning & Quantization
* Parameter-Efficient Fine-Tuning (PEFT / LoRA / QLoRA) on open-source LLMs (e.g., Llama, Mistral).
* Model evaluation, alignment, and optimization for edge deployment.

---

## 🧰 Tech Stack
* **Frameworks & Libraries:** PyTorch, Hugging Face Transformers, LangChain, LlamaIndex
* **Vector Databases:** ChromaDB, FAISS
* **Models:** OpenAI API, Llama, Mistral, Ollama
* **Languages:** Python
